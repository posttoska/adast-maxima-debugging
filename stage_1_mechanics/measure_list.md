# Tape-measure and photo list of the assembled model (Adast Maxima MS 115 PS, serial 578.0009)

Written by `stage_1_mechanics/assembly/merge_tables.py` (run by `assembly.py`); do not edit by hand, re-run the script. Every row is read at run time from the measure tables of the six part specs (`spec/<part>.md`); the `assembly.A*` rows are the assembly's own (photo requests of order 1 question 4, DECISIONS 3 and 4, clamp open item 1, and one row for each estimated body that no spec row covers).
IDs (identifiers) are part-qualified: `knife.M9` is row M9 of `spec/knife.md`. Units mm (millimetres); X + to the operator's right, Y + from the cutting line toward the rear, Z up from the floor. Classes: D drawing, T table or text, P photo proportion, E estimated, W web (counts as E, weaker than the machine's own documents).
Abbreviations: GLB (binary GL Transmission Format, GL = Graphics Library: the model files `out/<part>.glb`), JSON (JavaScript Object Notation: the anchors files `out/<part>_anchors.json`), Fig. (figure), p. (page), vs (versus), incl. (including), Ø (diameter), kW (kilowatts), MPa (megapascals), /min (per minute), LED (light-emitting diode), DECISION n (a ruling of the meta orchestrator of the workflow); S12, Y01, OA1, M1 and the like in the text are device designations of the electrical legend (wiring set 568-70.9001) and of the hydraulic parts list, not abbreviations. The rows quote each spec's own source keys, for example OM (operating manual of this variant), P7 or p7 (OM page 7), F101 (OM Fig. 10.1), PLAN (OM Fig. 4.2.2, the foundation plan), PL (packing list 578.0009), CERT (certificate of this machine), HC (hydraulic circuit diagram), HS2 (that circuit drawn in state 2, pre-clamp), HL (hydraulic parts list), OLD and OLD-I (the Russian manual of the older relay variant МС 115 Стандарт/Максиматик, and its Fig. I), FR (the frame's interface: `out/frame_anchors.json` and `spec/frame.md`), PH-stand or PH150610 (one machine photo), W568 (wiring set 568-70.9001 of this machine), W554 and W552 (wiring sets of other types). A key means what its own spec says (W1 is the knife price list on the web in `spec/knife.md`, and sheet 1 of wiring set 568-70.9001 in `spec/backgauge.md`); every spec's keys with the files they resolve to are listed in `sources.md`, section 'Source keys of each spec and the files they resolve to'.

Rows per spec: frame 26; knife 16; clamp 10; backgauge 41 + 10 gap groups; housing 18; safety_sensors 9; together 120 measure rows + 10 gap groups; assembly rows 5.
