Machine: Adast Maxima MS 115 PS, serial 578.0009. Units mm. Coordinates (section 05): X along the knife, + to the operator's right; Y + from the cutting line toward the rear; Z up from the floor. Classes: D drawing, T table/text, P photo or drawing proportion, E estimate, W web. Built **at rest = pusher face at Y 1150** (rear end = the S27 reference end); every moving item carries its motion.

## Files and how to run
Run from the work folder C:/Users/ptsk/Documents/adast-maxima-debugging with Python and numpy, trimesh, manifold3d (section 13 of the block). Rebuild first, then the checks, the render last.
- `python stage_1_mechanics/parts/backgauge/backgauge.py` builds every body and anchor from this spec (model table and anchors table, nothing else) and writes stage_1_mechanics/out/backgauge.glb, backgauge.stl and backgauge_anchors.json. Expected: 33 bodies, 17 anchors, bounds equal to the outer size given below.
- `python stage_1_mechanics/parts/backgauge/check_spec.py [--spec <md>] [--out <dir>] [--frame-anchors <json>] [--require-frame-names] [--parts-dir <dir>]` runs checks 7-11 of section 04 for this part, its own check 7b (the Components cells' positions at rest = the built bodies, ±1 mm, in five lines: the ranges of each axis; each ";" part of a cell as one body's extent, both mirror bodies for ±(a..b); the single values: axis lines, "(centre n)" and "front at"; the relations: gear left of the handwheel (маховичок) knob, carriage (тележка седла) centred on the nut, eye on the shaft axis, knob behind table.front_edge, S24 and S27 at table.underside of the frame anchors; every number of a cell checked by one of these) and its own check 12 (Space: which bodies leave the frame keepout, and into which room), against this spec, out/frame_anchors.json and out/frame.glb. --spec and --out build the model from another spec copy into another folder first; --frame-anchors takes another frame anchors file; --require-frame-names restores the old rule (the frame must name each passage), which fails both passages on the real frame file until thread 7 cuts them (DECISION 2). Expected without options: 60 PASS, 0 FAIL, exit 0 (2026-11-25, with the frame, knife and clamp files published; 7b: 55 axis ranges, 33 parts, 17 single values, 6 relations, 141 numbers, 0 unchecked). --parts-dir <dir> reads the other parts' anchors files from a copy (mutation_test uses it). Check 10 accepts a name that another part also publishes (today interface.clamp.comb_interleave, from the clamp) as a joint only if it is no device anchor and both files give the same point within 1 mm (meta orc ruling in TESTERS_RESULT_t4_r5; critic t4 g10).
- `python stage_1_mechanics/parts/backgauge/mutation_test.py` (under a minute; log it to a file) runs the base check, a copy test of the frame-named rule, 21 spec mutants that check_spec must each fail, and 2 mutants on a copy of the other parts' anchors files (the clamp's joint moved 5 mm; sensor.S24 added at the backgauge's own point) that check 10 must fail. Expected: PASS, 21/21 spec mutants and 2/2 parts-copy mutants caught, no mutant "not applied".
- `python stage_1_mechanics/parts/backgauge/xcheck_parts.py [--out <dir>]` intersects the backgauge with every other published part except the frame (check_spec covers it), at rest and with the moving group over the whole travel in 5 mm steps. Expected: RESULT PASS 0 (2026-11-25: clamp and knife, 0 overlaps).
- `python stage_1_mechanics/parts/backgauge/handwheel_check.py [shift ...]` moves the handwheel (маховичок) group (knob, shaft, gear) at rest and pushed in 2,5 / 5 / 7,5 / 10 mm along −X and intersects it with every other published part and the backgauge's own other bodies (bracket included). Expected: RESULT PASS, 0 overlaps at each step; the probe `handwheel_check.py -12` must report overlaps with the bracket leg and eye (2026-11-25: 776 and 1311 mm³).
- `python stage_1_mechanics/parts/backgauge/render_views.py` (plain python, not python -I: PIL is in the user site) builds the bodies from this spec, as backgauge.py does (not from the GLB file), and writes stage_1_mechanics/parts/backgauge/renders/backgauge_views.png and backgauge_views_small.png: top view at rest, side views at both travel ends, front view. Run it after every rebuild.

## Model table (machine-readable; parts/backgauge/backgauge.py builds every body from this table and nothing else)
Same numbers as the components table above, written out at rest (f = 1150). Group: moving = moves with the face along −Y by d = 1150 − face Y (0..1125); spindle = turns about the spindle axis, fixed in place; handwheel = knob, shaft and gear turn about their axis X and push in along −X; fixed = does not move. Kinds: box x y z; cylx = cylinder along X, c = y,z of the axis, s = x range, di makes it a tube; fingers = n plates w wide spread evenly over x; prism = polygon xy (x,y;...) extruded over z; cyl / tube = along Y, c = x,z of the axis, d outer, di inner; diamond = square turned 45° about Y, |x−cx| + |z−cz| ≤ r, bore along Y; channel = U open at the top, sheet t; boxbore = box with a bore of d along Y at c.
