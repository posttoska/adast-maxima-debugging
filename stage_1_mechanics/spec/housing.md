Units: millimetres (mm). Coordinates as the frame: X along the knife, + to the operator's right; Y + from the cutting line toward the backgauge; Z up; X 0 cut centre, Y 0 cutting line, Z 0 floor. Built at rest (knife up, clamp up). Minus signs are ASCII "-" so that check_spec.py can read every number.
Classes: D drawing number, T table or text, P photo or drawing proportion (ratio x a reference length), E estimate, W web. Every P and E value names its measure row (M1..M18 below). O = opening between the frame columns' inner faces = 1440 (frame, E +-120).
Script: parts/housing/housing.py builds every body of the table below, runs its checks and writes out/housing.glb, out/housing.stl, out/housing_anchors.json, out/housing_report.json. parts/housing/check_spec.py reads this file and checks those outputs against it. parts/housing/mutation_test.py runs a clean baseline (no error planted: every check must pass) and then plants errors that the checks must catch (the Run section gives the count): in the model (among them boxes that only the knife stroke, the clamp stroke or the backgauge travel reaches, and the r2 lamp positions), in a temporary copy of the published anchors files (switch.Q1 twice; a source key dropped), and in this file. parts/housing/render_views.py draws front, right-end, left-end and plan views (parts/housing/renders/housing_views.png).

## Run
From `stage_1_mechanics/` (of the work folder or of a copy), in this order after any change to this file or to a constant in housing.py:
- `python parts/housing/housing.py` (option B, DECISION 3; `--option A` builds the loser, whose overlap with frame.column_left makes checks 3 and 6b FAIL): writes out/housing.glb, .stl, _anchors.json, _report.json; last line `housing option B | 10 bodies | ALL PASS`, exit 0. Lines 8 and 9 print INFO (information only, not part of the pass).
- `python parts/housing/check_spec.py [--sources <folder holding preparatory_data_analysis>]`: first line names the sources root used; last line `check_spec housing: ALL PASS`, exit 0. On a copy without preparatory_data_analysis next to its stage_1_mechanics it falls back to the work folder C:/Users/ptsk/Documents/adast-maxima-debugging; the spec, out/ and crops are always the copy's own.
- `python parts/housing/mutation_test.py`: last line `mutation test housing: clean baseline PASS, 23 planted errors, ALL CAUGHT`, exit 0.
- `python parts/housing/render_views.py`: draws parts/housing/renders/housing_views.png (view it to check).
