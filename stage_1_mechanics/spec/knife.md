Units: millimetres (mm) everywhere. Coordinates as the frame: X along the knife, + to the operator's right; Y + from the cutting line (линия разреза, P7 §1.3.2) toward the backgauge (rear); Z up; X 0 middle of the cutting width, Y 0 cutting line, where the knife edge (режущая кромка резца, P34 §6.7, P42 §8.5) meets the cutting stick (режущая планка, марзан; P11 item 7), Z 0 floor. Built at rest: knife up, crank at top dead centre (TDC).
GLB (binary GL Transmission Format) convention: millimetres, Z up, machine coordinates, not converted to glTF metres / Y up; one node per body named `knife.<id>`.
Class: D drawing, T table or text, P photo or drawing proportion, E estimated, W web (counts as E). Every E value has an error and a measure row (M1-M16 below; the line "Measure rows per body" under that table maps every model row to its row).

## Conflicts settled
1. Worm-wheel height: p.19 elevation and Fig. 4.3 are the same front view and both put the wheel just below the table band with the worm under it (P19 scaled: centre Z 794, worm axis Z 628; F43: 897 / 645, less consistent with a worm mesh). Winner P19: centre Z 795, worm axis Z 629. Loser: the phrase "worm gear upper right" of the memory block, a plan reading (plans have the rear on top) = rear right, which agrees with the gear box behind the right column in F71 and F101.
2. Right protrusion: the front views draw flywheel and cover 200-240 beyond the right frame line; printed Fig. 4.2.2 gives +1553 − 1400 = 153. Printed wins: flywheel and slip rings end at X 1540, 13 left for the cover (housing thread).
3. M1 speed: P44 1800/min (rule: this manual) vs HL 1420 min⁻¹; 1800 is implausible for a 4-pole 50 Hz motor. Not a geometry value; read the plate (M8).
4. Knife path and crank radius, both E; site decides (M2). Modelled: straight vertical path. With the drawn crank centre C (935, 795) and rest pin H (660, 1135), dX 275, a full turn on a vertical path needs L − r ≥ 275, so r ≤ 81; r 51,52 is derived below from stroke 150. Against it: (a) the drawn eccentric circle sits 95-120 from the wheel centre (P19), and F62 draws the crank pin ≈ 0,62 of the wheel's outer radius off the shaft axis (≈ 80-87; soft critic t2, finding G); (b) the rod then stands 39,0° (rest) to 55,4° (bottom) off the path, so the guides would carry an X side load of tan 39° to tan 55° = 0,81-1,45 × the cutting force, implausible for sliding guides; (c) OLD says "наклонное движение" (inclined motion; other variant, same model name), and the eccentric pins (цапфы) at both upper ends would fit the pivots of a swinging holder. Alternative, not modelled: a path inclined down toward the crank. With C and H fixed and the drawn r 95 / 110 / 120, a full turn needs ≥ 4,6 / 9,2 / 12,2° from vertical (distance from C to the path + r ≤ L); a vertical stroke that fits under the crossbar (150-250) then needs 10-56° and an X shift of the holder of 45-222 between rest and bottom, more than the 16 left between the holder ends and the cheeks (computed by actor t2 g2; first raised by the soft critic t2).
