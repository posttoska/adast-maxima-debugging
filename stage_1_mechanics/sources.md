# Source table of the assembled model (Adast Maxima MS 115 PS, serial 578.0009)

Written by `stage_1_mechanics/assembly/merge_tables.py` (run by `assembly.py`); do not edit by hand. One row for each spec row of each body of `out/assembly.glb` (a body with feature rows, such as the frame table's slot, has several). Columns: the body (`<part>.<body>`), the spec row and its Russian or Czech term as the spec gives it, the spec's size and position, the model's bounding box after assembly, the spec's source text (pages, figures, photos), the files its source keys resolve to (checked to exist), class, error, and the measure rows that cover it.
File prefixes: OM/ = preparatory_data_analysis/maxima_documents/adast_guillotine_operating_manual/ (the operating manual of this variant), DOC/ = preparatory_data_analysis/maxima_documents/, PH/ = preparatory_data_analysis/maxima_photos/, ART/ = static_dynamic_memory/blocks/generation_001/artifacts/ (crops and saved web pages). Classes: D drawing, T table or text, P photo proportion, E estimated, W web (weaker than the machine's own documents and photos, marked 'weaker (web)').
Abbreviations: GLB (binary GL Transmission Format, GL = Graphics Library: the model files `out/<part>.glb`), JSON (JavaScript Object Notation: the anchors files `out/<part>_anchors.json`), Fig. (figure), p. (page), vs (versus), incl. (including), Ø (diameter), kW (kilowatts), MPa (megapascals), /min (per minute), LED (light-emitting diode), DECISION n (a ruling of the meta orchestrator of the workflow); S12, Y01, OA1, M1 and the like in the text are device designations of the electrical legend (wiring set 568-70.9001) and of the hydraulic parts list, not abbreviations. The rows quote each spec's own source keys, for example OM (operating manual of this variant), P7 or p7 (OM page 7), F101 (OM Fig. 10.1), PLAN (OM Fig. 4.2.2, the foundation plan), PL (packing list 578.0009), CERT (certificate of this machine), HC (hydraulic circuit diagram), HS2 (that circuit drawn in state 2, pre-clamp), HL (hydraulic parts list), OLD and OLD-I (the Russian manual of the older relay variant МС 115 Стандарт/Максиматик, and its Fig. I), FR (the frame's interface: `out/frame_anchors.json` and `spec/frame.md`), PH-stand or PH150610 (one machine photo), W568 (wiring set 568-70.9001 of this machine), W554 and W552 (wiring sets of other types). A key means what its own spec says (W1 is the knife price list on the web in `spec/knife.md`, and sheet 1 of wiring set 568-70.9001 in `spec/backgauge.md`); every spec's keys with the files they resolve to are listed in `sources.md`, section 'Source keys of each spec and the files they resolve to'. Also in the source table: CZ (Czech), TDC (top dead centre), DC (direct current), В (volt, in Russian text), daN (decanewtons), dm³ (cubic decimetres), cm² (square centimetres), mm/s (millimetres per second), px (pixels of a photo or page image).
