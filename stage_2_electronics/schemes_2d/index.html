Adast Maxima MS 115 PS (serial 578.0009, 1998): electrical schemes, stage 2

The electrical installation of the paper guillotine, redrawn in 2026 from the wiring set 568-70.9001 [SCHÉMA ZAPOJENÍ] of 1998 and the cabinet photos (not original documents). The 2D (two-dimensional) sheet pages follow 568-70.9001 sheet by sheet with its column numbers; the overview and the connections page join them; the 3D (three-dimensional) electrical layer sits on the stage-1 mechanical model in one offline viewer. Every device, wire and number carries a source path and a mark: sure, [?] (unclear), estimated ±error or W (web source, weaker). Designations as printed on the sheets; PLC (programmable logic controller) addresses as IN-x and OUT-x. Text in English with Czech and Russian terms in brackets; sizes in mm (millimetres).

Rebuild and check

Run from the folder that holds stage_1_mechanics and stage_2_electronics (the repository root), in this order; each command ends with a result line, the last one writes checks/checks.txt. The sheet pages and the 3D layer are written by the thread scripts named in their specs. Stage 1 is only read, never written.

python -B stage_2_electronics/schemes_2d/integration_merge.py
python -B stage_2_electronics/schemes_2d/integration_draw.py
python -B stage_2_electronics/schemes_2d/integration_lists.py
python -B stage_2_electronics/viewer/build_combined.py
python -B stage_2_electronics/checks/run_checks.py

Two longer runs test the checks and the commands themselves. Each copies the repository into new temporary folders outside it, works only there and deletes nothing. mutation_run.py breaks each check on purpose, one break at a time, and shows that the check then fails (checks/mutation_report.txt). copy_run.py runs the five commands above word for word in three copies: the committed files, the committed files with the local tables, and the files a clone from GitHub holds; it compares what they write with the repository and names each line of checks.txt that differs, with its reason (checks/copy_report.txt). Run the copy run after run_checks.py: it compares with the current checks.txt.

python -B stage_2_electronics/checks/mutation_run.py
python -B stage_2_electronics/checks/copy_run.py

What the set does not know yet

  • Cable routes are estimated: the bundles follow likely paths along the frame; legs nobody has seen are ±200 mm, the console end of bundle B1 ±100 mm.
  • The cabinet is built as option B (X −1420 … −1250 mm). Option A would move the cabinet, Q1, Q2, S4, S2 and the connectors XC1-XC4 by +113 mm in X.
  • S12, S13 and S14 (knife position sensors on the cam) are placeholders: their place, facing and cam reading are not known.
  • FF1 (light curtain) is not fitted on this machine (its certificate entry is a dash); no box is drawn.
  • 4 bodies of the stage-1 model that our items attach to touch no other body (backgauge.M2, clamp.valve_block_ov2, safety_sensors.M3, safety_sensors.Y3); they stay as built, stage 1 is read-only.
  • Every [?] and estimated row, and every place where a cabinet photo differs from the 568 print, is on the on-site measure list.
